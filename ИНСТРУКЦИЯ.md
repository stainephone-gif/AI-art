# Пошаговая инструкция к программе классификации теорий сознания в AI-арте

## Что делает программа

Программа анализирует текстовые описания произведений AI-арта и определяет, какую теорию сознания тематизирует художник. Она ищет многоуровневые метафоры — в том числе "метафоры метафор", когда художник берёт научную метафору ("мозг как компьютер") и превращает её в художественный образ ("алгоритм как художник").

Классифицируются 8 категорий:

| Код | Теория |
|-----|--------|
| COMP | Вычислительный функционализм |
| IIT | Теория интегрированной информации |
| PRED | Предиктивная обработка / свободная энергия |
| GWT | Теория глобального рабочего пространства |
| ENACT | Энактивизм |
| PAN | Панпсихизм |
| EMERG | Эмерджентизм |
| UND | Не определено |

## Шаг 1. Требования к системе

Убедитесь, что установлен **Python 3.8 или новее**:

```bash
python --version
```

---

## Шаг 2. Установка зависимостей

В папке проекта выполните:

```bash
pip install -r requirements.txt
```

Устанавливаются библиотеки: `pandas`, `openpyxl`, `requests`, `python-dotenv`, `matplotlib`, `seaborn`.

---

## Шаг 3. Получение API-ключа

1. Зайдите на [openrouter.ai](https://openrouter.ai) и зарегистрируйтесь.
2. В личном кабинете создайте API-ключ.
3. Скопируйте ключ — он понадобится на следующем шаге.

---

## Шаг 4. Настройка конфигурации

Скопируйте файл примера и создайте файл `.env`:

```bash
# Linux / macOS
cp .env.example .env

# Windows
copy .env.example .env
```

Откройте файл `.env` в любом текстовом редакторе и замените `your_api_key_here` на ваш ключ:

```
OPENROUTER_API_KEY=sk-or-xxxxxxxxxxxxxxxxxxxxxxxx
```

По желанию смените модель (строка `OPENROUTER_MODEL`):

```
# Примеры альтернативных моделей:
OPENROUTER_MODEL=anthropic/claude-opus-4-5
OPENROUTER_MODEL=openai/gpt-4-turbo
OPENROUTER_MODEL=google/gemini-pro
```

## Шаг 5. Подготовка входных данных

Входной файл — `combined_ai_preprocessed.xlsx` — уже находится в папке проекта. Он содержит описания произведений AI-арта.

Если вы хотите проанализировать свои данные, убедитесь, что ваш Excel-файл называется `combined_ai_preprocessed.xlsx` и содержит колонки с названиями и описаниями произведений.

## Шаг 8. Просмотр результатов

После завершения в папке проекта появится директория вида `enhanced_analysis_results_YYYYMMDD_HHMMSS/` (или `analysis_results_*/` для стандартного классификатора).

### Содержимое папки результатов

| Файл | Содержимое |
|------|-----------|
| `enhanced_analysis_summary.txt` | Краткое резюме анализа в читаемом виде |
| `enhanced_classification_results.json` | Полные результаты в формате JSON (все метафоры, оценки, уверенность) |
| `enhanced_classified_data.csv` | Таблица с исходными данными и классификациями (CSV) |
| `enhanced_classified_data.xlsx` | То же самое в формате Excel |
| `enhanced_analysis.png` | 9 графиков: распределение теорий, доля мета-метафор, гибридность и др. |

### Как читать JSON-результат

```json
{
  "primary_class": "PRED",        // Основная теория
  "confidence": "high",           // Уверенность: high / medium / low
  "is_hybrid": true,              // Гибрид нескольких теорий?
  "secondary_class": "COMP",      // Вторичная теория (если гибрид)
  "scores": {
    "PRED": 0.9,
    "COMP": 0.3
  },
  "metaphor_analysis": {
    "meta_metaphor_detected": true,              // Найдена "метафора метафоры"?
    "artistic_transformation": "scientific concept → artistic practice"
  }
}
```

### Интерпретация результата

- **`confidence: "high"` + `meta_metaphor_detected: true`** — художник сознательно работает с теорией сознания.
- **`is_hybrid: true`** — произведение сочетает несколько теорий (это норма для современного AI-арта).
- **`primary_class: "UND"`** — текст не содержит явной теоретической тематизации.

## Шаг 9. Решение типичных проблем

### Ошибка "API key not found" / "401 Unauthorized"
- Проверьте, что файл `.env` находится в папке проекта.
- Убедитесь, что ключ указан верно: `OPENROUTER_API_KEY=sk-or-...` (без лишних пробелов и кавычек).

### Ошибка "429 Too Many Requests"
- Программа автоматически делает паузу и повторяет запрос.
- Если ошибки продолжаются, добавьте в `.env`:
  ```
  RATE_LIMIT_DELAY=2.0
  ```

### Ошибка при чтении Excel
- Проверьте, что файл `combined_ai_preprocessed.xlsx` не открыт в другой программе.
- Убедитесь, что в файле есть ожидаемые колонки с названиями и описаниями.

### Программа зависает
- Нажмите `Ctrl+C` для остановки. Уже обработанные результаты не сохраняются автоматически — запустите заново.

## Шаг 10. Программное использование (для разработчиков)

Если нужно встроить классификатор в собственный скрипт:

```python
from enhanced_classifier import EnhancedMetaphorClassifier

classifier = EnhancedMetaphorClassifier()

# Классификация одного текста
result = classifier.classify_description("Нейросеть создаёт образы, подобно воображению...")

print(result['primary_class'])                          # PRED
print(result['metaphor_analysis']['meta_metaphor_detected'])  # True

# Пакетная обработка
descriptions = ["текст 1", "текст 2"]
titles = ["название 1", "название 2"]
results = classifier.classify_batch(descriptions, titles)
```

Для работы только с анализом метафор (без LLM):

```python
from metaphor_analyzer import MetaphorAnalyzer

analyzer = MetaphorAnalyzer()
evidence = analyzer.extract_metaphors("генеративная модель действует как воображение")

for e in evidence:
    print(e.theory_class, e.level.value, e.weight)

network = analyzer.analyze_metaphor_network(evidence)
print(network['meta_metaphor_detected'])   # True
print(network['dominant_pattern'])         # PRED
```
